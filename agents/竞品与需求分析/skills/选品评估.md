# 选品评估

## 适用场景

用户想知道某个品类或产品值不值得做、能不能做、风险在哪。输入可以是关键词/品类名，也可以是具体 ASIN。

## 执行步骤

### 步骤1：解析输入

判断输入类型：
- 关键词/品类名 → 从市场数据切入，做全链路评估
- ASIN → 先查产品详情，锁定所属细分市场，再做评估

向用户展示："正在评估 [关键词/产品] 的市场机会..."

### 步骤2：市场规模与趋势

调用 `关键词详情查询`（amzSite: "US"）
记录：月搜索量、搜索排名、CPC、竞品数量、首页评论数分布。

调用 `关键词趋势查询`（amzSite: "US"）
记录 24 个月趋势，判断增长/平稳/下滑，识别季节性。

向用户展示："市场规模数据已获取，[关键词] 月搜索量 [X]，趋势 [增长/平稳/下滑]"

### 步骤3：竞争格局

调用 `搜索结果查询`（page=1, page=2）
提取前 40 名产品，分析：
- 价格带分布（找空缺带）
- 头部品牌集中度（Top5 品牌销量占比）
- 新品进入难度（近 90 天上架产品数及表现）

对销量 Top5 调用 `产品详情查询`，补充品牌、评分、上架天数。

向用户展示："竞争格局分析完成，头部品牌占比 [X%]，价格空缺带 [价格区间]"

### 步骤4：用户满意度与差评痛点

对销量 Top3 的产品调用 `产品评论查询`（Negative）
从差评中提取：
- 高频痛点（出现频率 + 严重程度）
- 退货相关投诉
- 用户期望但产品没做到的点

向用户展示："差评分析完成，Top3 产品共 [X] 条差评，主要痛点 [列举 2-3 个]"

### 步骤5：综合判断

基于以上数据，给出明确结论：

**进入建议**：建议进入 / 谨慎进入 / 不建议进入
**风险等级**：低 / 中 / 高
**关键判断依据**：列出 3-5 条支撑结论的核心数据点
**如果建议进入**：
  - 建议价格带
  - 建议差异化方向（基于差评痛点）
  - 需要规避的风险
**如果不建议进入**：
  - 主要障碍
  - 什么条件下可以重新考虑

向用户展示："评估完成，综合结论：[进入建议]"

## 对话输出规范

- 每步完成后给用户简短进度提示
- 数据用表格展示
- 结论必须明确，不用"可能""也许""大概"
- 每个结论附带数据依据
- 风险和机会用明显标记

## 报告章节模板

### 第一章：市场概况
- 核心市场数据表（月搜索量、CPC、竞品数量、趋势方向）
- 季节性判断

### 第二章：竞争格局
- 价格带分布表
- 头部品牌格局表（品牌、销量占比、代表产品）
- 新品进入难度评估

### 第三章：差异化机会
- 差评高频痛点表（痛点、频率、严重程度）
- 用户期望缺口
- 可切入的差异化方向

### 第四章：综合结论
- 进入建议（建议进入 / 谨慎进入 / 不建议进入）
- 风险等级（低 / 中 / 高）
- 关键判断依据表
- 如果进入：建议价格带、差异化方向、风险规避
